## About

I’m a Computer Science student who likes learning by building. Most of my work sits around web applications, backend development, AI-assisted systems, and the engineering practices that make projects easier to maintain.

I’m less interested in collecting technologies and more interested in understanding how they fit together — from a clean API and database design to a frontend people can actually use.

- 🎓 Computer Science student
- 🧱 Interested in backend and full-stack engineering
- 🤖 Exploring AI and computer vision through practical projects
- 🔧 Learning architecture, testing, CI/CD, and deployment
- 🌱 Building, breaking, refactoring, and learning along the way
